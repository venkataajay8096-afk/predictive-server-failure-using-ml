Quick Setup Guide

  1. 1
    Start MySQL Server

    Make sure MySQL is running on your machine (e.g., via XAMPP, MySQL Workbench, or as a Windows service).

  2. 2
    Fill in Credentials

    Enter your MySQL host, port, username, password, and target database name on the left.

  3. 3
    Test the Connection

    Click Test Connection to verify SentryML can reach the MySQL server.

  4. 4
    Save & Initialize

    Click Save & Connect. The app will create the database, tables, and seed the ML models automatically.

  5. 5
    Restart the Server

    After saving, restart app.py for the new database to take full effect.
